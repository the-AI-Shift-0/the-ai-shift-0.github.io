AI Copywriter

Demo 1: real ChatGPT project. Demo 2: the Trove opt-in.

Before you hit record

  • Hide at capture, never in post: Dock, app sidebar, bookmarks bar, URL bar.
  • Filename pass. Read every filename twice. Rename any client, staff, launch or internal name.
  • Rename the project - it shows in the sidebar and tab title.
  • Clean profile: no extensions, no other tabs, Do Not Disturb.

It is the beat we sell and the top leak risk.

Demo 1 - your real ChatGPT project

  • Real project, real files, real output. No simulation.
  • 60-90 sec, fast cuts.
  • Record the generation, editor speed-ramps it. Run it twice.

Beat 1 - the shelf (15s)

  • One slow continuous scroll down the file list. No cuts.
This is the project. Everything that ever made us money is in here - years of our own winning copy, the customer's exact language, and the best copywriters alive. All loaded in before I type a single word.

Beat 2 - one line (10s)

Write the full launch campaign for [product] - sales page, five-email sequence, three ad variations.
  • Swap [product] for the real offer. Rest verbatim.
Watch what one sentence does.

Beat 3 - the pour (25s)

  • Sales page, five emails, ads. Scroll with it.
A full sales page. Then five emails. Then the ads. In my voice, using my customers' words - because it already knows all of it.

Beat 4 - the hold (15s)

  • Hold on one finished piece, long enough to read.
Read that. That's not generic AI copy. That's better than anything my team ever handed me - and it wrote the whole campaign while I sat here watching.

Blur / show / never say

BlurShow sharp
Revenue, spend, salary figures. Client and staff names. Customer names in quoted emails. Demo 2: test email, your name in the form, other inbox senders/subjects. File list. Campaign structure. Generated copy. Form labels. File contents. Prompt pack.

Never say: project knowledge, corpus, context window, fine-tune, RAG, token, prompt engineering.

Shot order

  1. Form submitted.
  2. Email arriving.
  3. Open the file, scroll slowly, hold on customer language.
  4. Fresh project, file added.
  5. Prompt pack.
  • No live generation in Demo 2.
  • Generate a fresh file on the day - section order may differ.
  • Continuity: "This took nine seconds" only works if the clip runs nine seconds. Match the stated duration to the footage, or state none.
