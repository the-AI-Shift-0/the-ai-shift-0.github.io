Recording cheat sheets

One sheet per video. Open the sheet for the video you are recording - each one is self-contained and prints on its own.

Standing recording rules - do these before you hit record

  1. Hide the macOS Dock. System Settings > Desktop & Dock > Automatically hide and show the Dock: ON.
  2. Hide the app sidebar. ChatGPT, Claude and Gemini all collapse theirs - collapse it before the first frame, not mid-take.
  3. Hide the browser bookmarks bar. Cmd+Shift+B.
  4. Hide the URL / address bar wherever possible. Full screen, or a distraction-free window. Where the URL has to be visible because it is the point, show only that one URL and nothing around it.

Why: the frame should show the work, not the machine. Every one of these is a leak path - open tabs, bookmarks, internal URLs, folder names and staff names have all reached a customer-facing frame before. Hiding them costs four seconds and removes the whole class of problem.

Read this before you use any sheet

  • Every sheet ends with OPEN QUESTIONS. Those are the things only you can answer. Answer them before filming day, not on it - several of them change what gets said on camera.
  • Anything a sheet marks as unverified stays off screen and out of the voiceover until it has been checked. An unverified number on screen is a re-shoot.
  • If the built demo and the script disagree, the built demo wins - show what actually exists and change the spoken line to match. The reverse has cost a re-shoot before.
